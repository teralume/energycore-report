# Inventario de artefactos complementarios AV1

Este paquete reúne los artefactos reales disponibles para sustentar el Primer Hito de EnergyCore. Los repositorios públicos conservan el código fuente y su historial; el ZIP concentra documentos, diseños, capturas, resultados técnicos y archivos ejecutables útiles para la revisión.

## Contenido incluido

- Project Report en Markdown y enlaces a los cinco repositorios públicos.
- Wireframes de Landing Page, Web Application y Native Mobile Application.
- Mockups de alta fidelidad y flujo principal de usuario en PNG y SVG.
- Capturas reales de Landing Page, Angular, Flutter Android, Swagger y GitHub.
- Contrato OpenAPI y resultados JSON de las verificaciones de preferencias y energía.
- Evidencia de despliegue público de la API y la experiencia web, sin credenciales.
- Primera entrevista de needfinding en video y su captura incorporada al informe.
- Participant Performance Report en DOCX y PDF.
- APK Android de tipo release y archivo de suma generado por Flutter.
- Material de preparación del Keynote y auditoría de evidencias. Los archivos finales PPTX y PDF se conservan como entregables independientes en `output/keynote` para evitar duplicarlos dentro del ZIP.
- `SHA256SUMS.txt` con la huella de cada archivo contenido en el ZIP.

## Elementos que el ZIP no sustituye

El paquete complementario no reemplaza los archivos de entrega independientes. El Keynote final ya está disponible en PPTX/PDF. Todavía debe exportarse el Project Report en PDF y deben producirse, después de completar las entrevistas, el video consolidado de needfinding, el Video About-the-Product y el video de exposición AV1 con sus enlaces de publicación.
